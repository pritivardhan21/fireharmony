# Data, software and references

## Data
- NASA FIRMS active-fire archive downloads for the box 73.8-77.6E, 27.6-32.6N, downloaded 12-13 October 2026: MODIS Collection 6.1 (dataset code M-C61), VIIRS S-NPP 375 m (SV-C2), VIIRS NOAA-20 (J1V-C2) and VIIRS NOAA-21 (J2V-C2). NOAA-20 and NOAA-21 were used for cross-checks only. Archive requests are not included in the repository.
- Not used in this version: MODIS data for 2002-2011 (the calendar starts in 2012).
- Acknowledgement: "We acknowledge the use of data and/or imagery from NASA's Fire Information for Resource Management System (FIRMS) (https://earthdata.nasa.gov/firms), part of NASA's Earth Science Data and Information System (ESDIS)."
- Basemap: OpenFreeMap (https://openfreemap.org) with (c) OpenStreetMap contributors; map rendering by MapLibre GL JS.

## Software
- Python: pandas, numpy, pyarrow, scipy, matplotlib
- Web: React, Vite, Tailwind CSS, Recharts, MapLibre GL JS
- Colour ramp: viridis (perceptually uniform, colour-blind safe)
